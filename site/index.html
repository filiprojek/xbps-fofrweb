xbps.fofrweb.net

Unofficial Void Linux package repository with packages that are not in the official one, for @ARCHS@ (glibc). Built from the templates on GitHub.

Use it

echo 'repository=@REPO_URL@' | sudo tee /etc/xbps.d/20-fofrweb.conf
sudo xbps-install -S
sudo xbps-install <package>

Accept the key on the first sync only if it shows:
signed by: @SIGNED_BY@
fingerprint: @FINGERPRINT@

xbps uses the first repository in /etc/xbps.d (alphabetical) that has a package, so with 20- the official build wins once Void ships it. Use 00-fofrweb.conf to prefer the builds from here.

Request a package

Open an issue with its name, homepage, licence and why it's needed here. Packages the official repository would take belong in void-packages.

Contribute

Packages are ordinary void-packages templates in srcpkgs/. Fork the repository, set it up as its README says, add srcpkgs/<package>/template (xnew, xgensum -i, xlint), build it with ./xbps-src pkg <package> and open a pull request.
